# PEEK

PEEK 是一款原生 macOS 菜单栏效率工具，提供本地文件查找以及截图、编辑、OCR、二维码识别与滚动拼接。

当前功能：

- 文件查找：默认在“全部”中检索应用程序、文件和文件夹；结果分为“应用结果”和“文档结果”，应用分组优先，同组内按匹配度排序
- 拼音与英文模糊查询：所有已索引 `.app` 统一读取当前语言、简体中文、繁体中文、英文和包名别名，支持中文全拼、拼音首字母、英文单词首字母和非连续字符匹配
- 持久化后台索引：查询只读取 SQLite 已提交快照；磁盘扫描由独立低占用周期任务完成
- 沙盒目录授权：应用目录只收录 `.app` 应用包，不收录系统文件；普通文件和文件夹只来自用户通过系统选择器明确授权的目录
- 双栏查找面板：左侧结果，右侧 Quick Look 预览/元数据，底部提供打开、复制、访达定位、复制路径、移动、复制到和隔空投送
- 区域截图：多屏冻结画面、像素取色、自由框选、窗口选取与键盘微调
- 图片标注：矩形、椭圆、箭头、直线、画笔、荧光笔、文字和序号
- 像素化马赛克、撤销与重做
- 多窗口钉图：置顶、拖动、缩放、旋转、透明度、复制与另存
- 滚动截图：手动/自动采集、重复帧过滤、重叠估算与纵向拼接
- 本地 OCR：使用 macOS Vision 识别中英文，不上传图片
- 二维码识别：选区形成后在后台进行一次低优先级、本地存在性检测；检测到二维码时只在选区工具栏下方提示用户点击二维码按钮，不自动打开结果，也不在 macOS 菜单栏下拉菜单显示二维码提示。用户主动点击后才识别文本、HTTP/HTTPS 网址或内嵌图片；文本可复制、网址由用户主动打开、内嵌图片可预览与保存
- 剪贴板优先：双击选区或点击完成直接复制，默认不创建历史截图文件；需要时可从工具栏显式保存
- 原生设置中心：参考 HapiGo 的原生 macOS 分区方式，提供“通用、搜索、快捷键、截图、外观、关于”六页配置；搜索页用“文档搜索、应用搜索、搜索排除”三个直观入口管理范围
- 中英双语：完整支持简体中文和 English，可跟随 macOS 系统语言，也可在设置中手动指定；为保证 AppKit 菜单、提示窗与 SwiftUI 页面一致，切换后需重新打开应用
- 可自定义全局快捷键：默认 `Control + Space` 打开文件查找，`Option + Command + 2/3/4` 分别启动区域、滚动和 OCR 截图
- 单实例运行：重复启动时激活已运行实例，不创建第二个常驻进程

项目不使用 CocoaPods、Homebrew 或第三方 Swift Package。完整范围与验收标准见 [`PRD.md`](PRD.md)。

## 在 Xcode 中运行

1. 双击 `PEEK.xcodeproj`。
2. 选择 Scheme `PEEK > My Mac`。
3. 按 `Command + R`。

项目最低支持 macOS 13.0。项目、Target、Scheme、模块、可执行文件和应用名称均统一为 `PEEK`，Bundle ID 为 `com.shawnshoper.peek`。Xcode Team 配置为 `4DXU5FSLLY`。这是新的 macOS 应用身份，首次运行需要重新授予截图、辅助功能与目录访问权限，旧应用容器中的设置和索引不会自动沿用。

当前机器已验证可使用 `Apple Development: Hao Xie (W5623GG28N)` 为 Debug 构建签名。运行截图功能时必须启动该正式签名构建；使用 `CODE_SIGNING_ALLOWED=NO` 生成的临时产物仍可能因代码身份变化导致 macOS 屏幕录制授权失效。

## Mac App Store 状态

SQLite 可以用于 Mac App Store 应用；项目链接的是 macOS 系统 `libsqlite3`，索引数据库只保存在应用容器内。主 target 已启用 App Sandbox、用户选择目录读写和 app-scoped bookmark，沙盒不会禁止文件索引，但只允许读取系统开放位置及用户通过系统面板授权的目录。

工程已提供完整 macOS `AppIcon` iconset，应用版本与 PRD 统一为 `0.3.0 (3)`。Apple Distribution / Mac App Store Archive 流程尚未验证；签名沙盒构建下的目录授权跨重启、截图 TCC 与空闲索引 60 秒 CPU 采样仍需实机验收。Apple 当前 Required Reason API 文档只把相关申报要求列于 iOS、iPadOS、tvOS、visionOS 和 watchOS；本 macOS-only、无第三方 SDK、无数据上报版本不因此虚构 `PrivacyInfo.xcprivacy`，但提交时仍需如实填写 App Store Connect 的 App Privacy 问卷。

## 首次使用

1. 按 `Control + Space` 打开文件查找；若它已被输入法或其他程序占用，应用会显示冲突，可从菜单栏打开并在“设置 > 快捷键”中改键。
2. 首次启动时，如果文稿、桌面或下载仍未被已有授权覆盖，PEEK 只提示一次打开“设置 > 搜索 > 文档搜索”。每个缺失目录右侧直接提供“授权”按钮，不显示警告图标，也不会连续弹出多个系统选择器。三个默认项使用登录账户的真实目录，不使用 App Sandbox 的容器 Home；旧版容器路径会自动迁移。默认项可逐项删除，“恢复默认”会恢复完整三项。应用目录可在“应用搜索”中删除、添加或恢复默认。查询只读取最近一次成功提交的 SQLite 索引；尚未完成后台索引的文件暂时查不到，也不会因为输入查询而临时扫描磁盘。
   首次后台任务在启动约 3 秒后尝试运行：先快速索引应用包，再快速索引用户已授权目录；界面会根据真实扫描吞吐显示预计剩余时间。每个目录使用独立 SQLite generation，提交后立即可查，不等待全局索引完成。首次快速档的 CPU 目标不超过单核 5%，元数据访问上限约 2,500 项/秒；系统目录中的普通文件和文件夹不会入库。后续增量维护恢复为单核 0.6% 目标、每秒约 160 个元数据项且不显示 ETA。设置页对每个配置目录提供独立“刷新索引”：大目录直接展示按钮，小目录和应用目录在行菜单中提供；同一时间只刷新一个目录，其余请求排队。常规维护周期为 30 分钟（系统可按电量、温度和活跃状态延后），每 7 天执行一次完整重建。文件复制或移动一旦开始，关闭查找浮窗不会中断系统文件操作；结果在 SQL 更新或下一个后台周期收口。
   每次增量维护优先处理 dirty 目录，并额外轮换一个最久未成功更新的已授权目录，因此 Finder、浏览器或下载器产生的外部变化也会逐轮被发现；授权目录较多时会按周期轮转，不承诺单轮全部刷新。
3. 先切换到要截取的窗口，再从菜单栏选择“区域截图”“滚动截图”或“OCR 截图”，也可按对应全局快捷键。
4. 首次截图时按系统提示授予“屏幕录制”权限。
5. 完全退出并重新打开 PEEK，使首次授权生效。
6. 尚未框选时，鼠标旁显示像素放大镜、HEX 与 RGB；单击复制当前色值，移动达到 `4pt` 才进入拖选，二者不会冲突。双击窗口可直接选取整窗；松开后在冻结选区下方显示横向工具栏，不再弹出独立编辑窗口。
7. 可在选区内完成标注、马赛克、OCR、二维码识别、钉图、复制或保存；选区含二维码时，工具栏下方仅显示一次点击引导，用户必须主动点击二维码按钮才会打开识别结果。支持工具栏放大/缩小、触控板捏合、双指平移及 `⌘+`、`⌘-`、`⌘0`。缩放只影响编辑视图，不改变原始像素和导出清晰度。工具栏出现后双击选区、按 `Enter` 或点击“完成”，都会把最终渲染结果复制到剪贴板。
8. 滚动截图会根据鼠标位置预选：鼠标位于直接命中的 `AXScrollArea` / `AXWebArea` 时框选该滚动区域；未命中时框选整个目标窗口，不再从窗口内其他 iframe 或滚动节点猜选。开始拖动、移动或缩放后立即停止自动跟随，最终以用户自定义选区为准。

自动模式采用保守步长：正常情况下每次滚动不超过选区高度的 35%，同时受设置中的像素上限约束，并以选区高度的 45% 作为不可突破的硬上限；小选区不会被强制提高到 100 像素。这样会增加采集帧数，但能为相邻帧保留更多重叠内容。

如果出现重叠识别失败、滚动区域边界变化、目标没有滚动或目标窗口变化，恢复提示会提供“减小步长并重新框选”“重新框选”“切换手动”和“复制诊断”。若失败前已有至少 2 帧通过全部可靠性校验，还会提供“编辑并保存已完成部分”；该结果只包含失败前的可靠前缀，并会明确标记为部分结果，不会被静默当作完整长图。第 2 帧首次匹配就失败时不提供此选项。诊断只包含错误、模式、选区、实际步长及窗口标识等文字，不包含也不保存截图。重新采集前，应先把页面滚回本次开始位置（通常是页面起点）；如果尚未复位，请取消提示，复位后再发起，避免结果缺少前段。

全局快捷键可在“设置 > 快捷键”中修改。点击当前组合后直接按新组合；`Delete` 停用，`Esc` 取消录入，“恢复默认”可恢复 `Control + Space` 与 `Option + Command + 2/3/4`。配置会在重启后保留，菜单栏同步显示当前组合。

## 设置功能

- 通用：登录时打开、仅菜单栏运行、查找窗口所在屏幕、窗口居中或记住位置、应用语言、恢复默认设置。
- 搜索：顶部使用原生“通用、搜索、快捷键、截图、外观、关于”图标工具栏，左侧仅保留“文档搜索、应用搜索、搜索排除”三个入口。文档搜索以“目录、权限、索引状态”三列表格和右侧详情区展示真实状态；缺失授权时直接显示“授权”按钮，父目录授权覆盖的子目录显示“已包含”。默认文档和应用目录均可逐项删除并一键恢复，应用搜索也可添加自定义应用目录；搜索排除初始为空，只显示用户自行添加的文件或目录。缓存、构建产物、版本库对象等内部安全跳过规则不作为可误删的用户配置展示。
- 快捷键：文件查找、区域截图、滚动截图、OCR 截图统一录入，展示系统冲突和注册失败原因。
- 截图：屏幕录制/辅助功能状态、剪贴板完成行为、自动识别滚动区、自动/手动滚动、滚动距离和最大帧数。
- 外观：跟随系统/浅色/深色、紧凑/标准结果密度、显示或隐藏右侧预览。
- 关于：版本、本地处理与授权边界、复制不含文件内容和搜索词的诊断信息。

设置项实时保存，不设置无意义的总“保存”按钮。应用启动后只显示菜单栏图标，不自动打开设置、搜索或截图历史主窗口。

保存快捷键前会检查 PEEK 菜单占用、四个动作之间的重复、macOS Symbolic Hot Keys，并使用 Carbon 独占注册处理注册竞态。macOS 的输入法切换常使用 `Control + Space`，检测到占用时默认快捷键不会注册，用户需在任一侧更换组合。macOS 不提供枚举所有第三方应用快捷键的统一公开接口；无法读取系统快捷键列表时，设置页会明确显示“检查受限”，而不会误报为完整无冲突。

普通区域截图在双击、按 `Enter` 或点击“完成”时直接复制到剪贴板，不自动生成历史文件；只有点击工具栏“保存”时才写入用户选择的位置。OCR 与二维码识别全程在本机处理。

自动滚动使用 macOS 的 Post Event 权限向用户确认的目标窗口发送滚轮事件，该权限由“系统设置 > 隐私与安全性 > 辅助功能”管理。没有权限时自动模式会明确停止；用户仍可切换手动滚动。

Mac App Store 的 App Sandbox 会限制跨应用读取完整 AX 层级，因此沙盒签名构建不能把 `AXScrollArea` / `AXWebArea` 自动识别视为必然可用：直接 hit-test 不可用时会预选目标整窗，用户可继续自由重画、移动或缩放选区；自动滚轮投递使用独立的 Post Event 权限。完整 AX 自动框选若作为硬性能力，需要另行评估非沙盒直接分发版本，不能通过私有接口或沙盒例外绕过。

“自动识别当前窗口的滚动区”默认开启：系统允许跨应用 AX hit-test 时，只对触发瞬间鼠标直接命中的元素沿父链选择最近滚动容器；沙盒阻止该读取时直接回退整窗。遮罩内不会从窗口内其他 iframe 或滚动节点猜选。识别只生成待确认选区，不会在用户确认前发送滚轮事件；用户开始移动、缩放或重新框选后，自动跟随停止，并按最终选区重新绑定精确窗口。

## 工程结构

```text
PEEK.xcodeproj
PEEK/
├── App/            App、Scene、菜单栏、单实例与全局快捷键入口
├── Services/       截图、剪贴板与 OCR 工作流编排
├── SearchKit/      SQLite 索引、沙盒目录授权、低占用后台调度与模糊匹配
├── SearchUI/       文件查找面板、Quick Look 预览与文件操作
├── ScreenshotKit/  ScreenCaptureKit/兼容捕获、选区、标注、马赛克、钉图、OCR 与滚动拼接
├── Views/          菜单栏与设置页面
└── Resources/      Info.plist、Assets 与中英 String Catalog
PEEKTests/      文件查找、截图、滚动拼接、错误提示与快捷键测试
```

## 命令行验证

完整的本地交付检查可直接运行：

```bash
./scripts/verify-release.sh
```

脚本会先检查所有用户可见中文文案均经过本地化、英文翻译完整且格式占位符安全，再执行 Swift 严格并发测试构建、全部 XCTest、Release Analyze、Universal 2 架构、AppIcon 资源和 `0.3.0 (3)` 版本一致性检查。它使用无签名构建，因此不替代真实 TCC、沙盒 bookmark 和 App Store Archive 验收。

无签名证书时，可关闭代码签名完成编译与测试验证：

```bash
xcodebuild -project PEEK.xcodeproj \
  -scheme PEEK \
  -destination 'platform=macOS' \
  CODE_SIGNING_ALLOWED=NO \
  build

xcodebuild -project PEEK.xcodeproj \
  -scheme PEEK \
  -destination 'platform=macOS' \
  -parallel-testing-enabled NO \
  CODE_SIGNING_ALLOWED=NO \
  test
```

`CODE_SIGNING_ALLOWED=NO` 只用于编译与自动测试，不代表屏幕录制 TCC 授权已可稳定复用。真实截图验收必须使用稳定签名的 App 构建，并由用户在系统设置中授权。

## 当前限制

- 文件查找使用应用自身的 SQLite 索引，不依赖 Spotlight。查询路径不枚举文件系统；索引未完成的内容就是暂时查不到。应用根目录仅收录 `.app` 包并跳过所有普通系统文件；文件和文件夹只扫描用户明确授权的目录。权限失效时保留上次完整代或停止展示已撤销目录。
- 首次和用户主动触发的目录索引使用快速档：应用目录优先，随后处理授权文件目录；使用 256 项微批次、单核不超过 5% 的 CPU 目标和每秒约 2,500 个元数据项的 I/O 代理上限。打开查找面板时索引暂停，已提交目录仍可查询；截图、OCR、文件操作、低电量或高温也会暂停索引。后续自动增量使用 16–32 项微批次、单核 0.6% 目标和每秒约 160 个元数据项，产品上限按 60 秒平均值低于 1% 验收，并在用户活跃或打开查找面板时暂停。设置页显示“已索引 / 已发现”动态计数，发现总数会随着枚举增长；扫描期间根目录发生变化会保留 dirty 标记并安排补充增量。已提交、可查询的索引最多 30 万项；为原子切换保留的 staging/旧代会占用临时数据库空间，并由低占用维护分批清理。
- 常规增量任务只扫描 dirty 根和一个轮换根，不做每 30 分钟全盘重建；来自其他应用的新增、删除或重命名可能要等对应根轮转后才反映。查询始终不会为了补齐这些变化而扫描磁盘。
- 索引数据库位于应用的 Application Support 容器中，使用系统 SQLite（WAL）；文件名、路径、拼音字段和索引状态只保存在本机。添加目录不立即扫描，移除授权后该目录结果立即停止查询，物理清理由后续低占用维护完成。
- 已提供正式 AppIcon；无签名构建成功仍不等于已通过 Mac App Store Archive、沙盒 bookmark、TCC 或 CPU 实机验收。
- macOS 14 及以上截图统一使用 ScreenCaptureKit，macOS 13 仅保留隔离的 Core Graphics 兼容后端；受保护窗口和 DRM 内容仍无法捕获。
- 滚动拼接会先排除与边缘连续相连且边界稳定的固定标题栏/侧栏，再重新估算正文重叠；遇到内部悬浮层、区域边界漂移、动画、视频或大面积重复纹理时会停止，不会强制输出可能错版的长图。停止后可降低单次步长并重新框选、重新框选纯正文或切换手动模式。
- 自动滚动只向用户最终选区绑定的精确窗口发送标准系统滚轮事件；每次投递前都会复核窗口身份、位置、前台状态和遮挡。首次试滚没有画面变化时会停止并提示，不会把单帧伪装成长图。
- 受保护窗口和 DRM 内容不能通过系统截图接口捕获。
- 部分不使用 Carbon 注册的第三方全局快捷键无法预先枚举；发生实际占用时需在任一应用中更换组合。
- 录屏、GIF、云同步与团队协作不在当前版本范围内。
