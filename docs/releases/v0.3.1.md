# PEEK v0.3.1

版本 **0.3.1（构建 5）**，包含 v0.3.0 之后的搜索索引、截图兼容性、剪贴板隐私和发布验证改进。

## 本次更新

- 文件索引上限提升至 **100 万项**。达到旧上限的索引会自动补做一次完整检查，期间保留已提交的搜索结果；暂缓或失败后可以重试，完成后恢复增量更新。
- 改善真实索引进度与状态展示，区分统计、索引、等待重试、容量不足和权限受限，避免提前显示完成。
- 监听文件系统变化，合并短时间内的事件，按变化文件或子目录更新；保存待处理事件和处理位置，支持重启后继续处理，并优先处理应用变更。
- 加强受限目录、扫描期间目录变化和未完成索引的恢复处理。搜索窗口打开时仍可继续索引，截图、OCR、文件操作和系统压力可让后台索引暂缓。
- 修复 macOS 26 及以上系统普通截图遗漏微信窗口的兼容问题；新的桌面截图路径仅用于 macOS 26 及以上。
- 剪贴板记录前检查保密、临时、自动生成和 1Password 标记，跳过带有这些标记的整次变化。该保护依赖来源应用提供标记，不能识别所有未标记的敏感信息。
- 改善搜索结果分组、内置工具操作、可访问性和中英文本地化；修正发布脚本的双架构校验方式。

## 安装与升级

- 支持 **macOS 13 Ventura 及以上**，同时支持 Apple Silicon（arm64）和 Intel（x86_64）。
- 推荐下载 `.dmg`，退出 PEEK 后将新版本拖入“应用程序”文件夹；也可下载 `.zip` 后解压安装。
- PEEK 是菜单栏应用，启动后请在屏幕顶部菜单栏寻找图标。截图需要“屏幕录制”权限，自动滚动截图需要“辅助功能”权限。
- GitHub 分发包采用 Developer ID Application 签名与 Apple 公证；具体源码提交、签名和公证记录见 `release-manifest.txt`，下载文件校验值见 `SHA256SUMS.txt`。

## 验证范围

发布验证覆盖 424 项自动化测试、Release Analyze、Universal 2 构建、本地化、资源和隐私清单检查。微信截图的人工确认来自当前测试设备，完整跨设备、旧系统及 VoiceOver 操作验收仍有待补充。

## 隐私

搜索索引、截图、OCR 和剪贴板历史默认保存在本机；剪贴板历史未额外加密。只有用户自行配置并主动使用云翻译时，待翻译内容才会发送给所选服务商。详见[隐私政策](https://github.com/ShawnShoper/peek/blob/v0.3.1/PRIVACY.md)。
