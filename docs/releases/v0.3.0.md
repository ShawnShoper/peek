# PEEK v0.3.0

PEEK 的首个公开版本：一款安静驻留在菜单栏的 macOS 文件查找、截图、剪贴板和翻译工具。

## 主要功能

- 快速查找应用、文件和文件夹，支持中文、拼音、首字母与英文模糊搜索。
- 应用结果按下 `Enter` 后立即收起面板并异步启动，减少可感知卡顿。
- 区域截图支持移动选区、八方向缩放、重新框选、标注、马赛克、OCR、二维码、钉图、复制与保存。
- 滚动长截图支持自动/手动滚动、自适应步长、尾部拼接和固定悬浮区域处理。
- 剪贴板历史最多保留最近 100 条，支持文本、图片、文件和链接预览。
- 独立翻译工具支持 Apple 本地翻译，以及由用户自行配置、默认关闭的百度和 Google 云翻译。
- 包含隐私说明、首次使用引导、后台搜索索引和权限状态检查。

## 系统要求

- macOS 13 Ventura 或更高版本。
- Universal 2：同时支持 Apple Silicon (`arm64`) 和 Intel (`x86_64`)。
- 截图需要“屏幕录制”权限；自动滚动截图需要“辅助功能”权限。
- PEEK 是菜单栏应用，启动后不会自动显示普通主窗口。

## 下载选择

- `.dmg`：推荐安装方式。打开后将 PEEK 拖入“应用程序”文件夹。
- `.zip`：便携压缩包。解压后将 `PEEK.app` 移入“应用程序”文件夹。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。
- `release-manifest.txt`：版本、源码提交、签名和 Apple 公证记录。

GitHub 附件使用 Developer ID Application 签名并经过 Apple notarization；Mac App Store 构建使用 Apple Distribution，由 App Store Connect 单独分发。

## 隐私

搜索索引、搜索词、截图、OCR、二维码和剪贴板历史默认只在本机处理。只有用户自行配置并主动使用云翻译时，待翻译内容才会直接发送给所选服务商。详见[隐私政策](../../PRIVACY.md)。
