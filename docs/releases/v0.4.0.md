# PEEK v0.4.0

版本 **0.4.0（构建 6）** 新增本地用量统计和成就勋章。

## 用量与勋章

- 打开「设置 → 用量」可以查看最近 22 周的每日热力图。将指针停在日期上可以查看当天次数。页面底部显示累计操作次数和日均次数，日均包含从首次成功操作到今天的所有自然日。
- 搜索结果操作、剪贴板历史恢复、截图输出、文字或二维码识别，以及翻译会在成功后计数。同一次翻译请求即使收到多个服务的结果也只计一次。
- 首次成功操作即可获得种子勋章，累计 50、300、3000 次分别解锁三枚效率勋章。绿色勾表示已获得。开启「挂载勋章」后，PEEK 菜单会显示当前最高勋章。
- 用量记录仅在这台 Mac 上保存日期和次数，从本功能首次记录起累计。[隐私政策](https://github.com/ShawnShoper/peek/blob/v0.4.0/PRIVACY.md)

## 安装与校验

支持 macOS 13 Ventura 及以上版本，安装包同时适配 Apple Silicon 和 Intel Mac。退出 PEEK，打开 DMG，将 PEEK 拖入「应用程序」后重新启动。也可下载 ZIP 解压安装。

发布附件包含 Developer ID 签名和 Apple 公证的通用安装包。`release-manifest.txt` 列出源码提交和公证记录，`SHA256SUMS.txt` 提供文件的 SHA-256 校验值。
