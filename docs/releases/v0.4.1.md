# PEEK v0.4.1

版本 **0.4.1（构建 7）** 修复了大型索引漏搜、回车打开旧搜索结果和取消后意外启动滚动截图的问题。

## 搜索与截图

- 搜索优先匹配完整文件名和前缀，已有索引可直接使用。模糊搜索超时后会自动补查一次，仍未查完时会显示提示。
- 改完搜索词立即按回车或数字快捷键，会打开当前查询的结果。应用启动较慢时，重新打开的搜索面板会保持可用。重新开启预览也能看到当前选中项。
- 取消区域或滚动截图后，旧选区不会再触发采集。随即发起的新截图可以继续进行。

## 剪贴板、翻译与用量

- 只有 HTML 或 RTF 的剪贴板内容现在也能显示正文和字符数。升级时会修复旧版误记为零字符的富文本摘要。一次复制超过 64 个文件时，历史记录会显示原数量和实际保留数量。
- 删除剪贴板记录遇到数据库忙碌时，原内容仍可读取。自动粘贴会确认原应用已回到前台，焦点改变时停止投递，内容保留在剪贴板中。
- 翻译选择「跟随系统」时，香港英语和台湾英语会正确使用英语。跨时区后，用量页的首次使用日期和日均值会与累计次数保持一致。

## 安装

支持 macOS 13 及以上版本，兼容 Apple Silicon 和 Intel Mac。打开 DMG，将 PEEK 拖入「应用程序」文件夹即可更新。附件中的 `SHA256SUMS.txt` 可校验安装包，`release-manifest.txt` 记录构建提交与 Apple 公证结果。
