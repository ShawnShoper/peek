# PEEK 2026年10月13日变更说明

本次源码更新集中改善搜索索引的进度、更新效率和异常处理，补充剪贴板隐私保护，并修复 macOS 26 上普通截图遗漏微信窗口的问题。

应用版本仍为 **0.3.0，构建 4**，Bundle ID 保持 `com.shawnshoper.peek`。以下内容对应上一提交 `13687b7` 之后的累计变更，不表示新的安装包或 App Store 版本已经发布。

## 截图兼容性

- macOS 26 及以上系统的初始桌面截图改用 Apple 公开的屏幕区域截图接口，避免沿用应用共享过滤路径。微信窗口可正常进入截图，已于 2026年10月10日由用户在已安装版本中确认。
- 保持显示器像素尺寸和 SDR 输出，不采集鼠标光标，不额外保存桌面原图，也不重复裁剪。
- 滚动截图和需要排除 PEEK 自身窗口的实时区域采集继续使用原有过滤路径；旧版 macOS 的捕获方式保持不变。
- 不修改微信设置、窗口共享属性、系统权限或快捷键。选区移动、缩放、标注、复制和保存沿用现有流程。

## 搜索索引进度

- 搜索栏下方新增索引状态与进度条，设置页使用相同的进度展示规则。
- 按阶段先统计总量再索引：优先统计并提交应用，再处理个人文件。索引时依据实际已处理数量与总量显示进度，并根据扫描期间新建或移除的项目调整总量。
- 统计总量、等待重试和异常阶段保留静态进度槽及状态，不使用左右滚动的蓝色动画，也不虚构百分比。
- 未完成全部目录时不提前显示完成；正常结束后隐藏搜索栏下方的进度区域。容量不足或索引失败时保留提示。
- 精简进度文字，突出阶段、目录名称和数量；完整路径与异常原因通过悬停提示查看。减少无变化状态和细微预计时间波动引起的重复界面更新。
- 紧凑搜索窗口向下增加进度区域，保持顶部位置；展开窗口不因进度显示而改变整体高度。

## 索引更新与可靠性

- 增加文件系统事件监听，合并短时间内的变更，按变化文件或子目录更新索引，覆盖新增、重命名和删除。
- 持久保存待处理路径和事件位置，支持重启后继续处理；事件丢失时校验受影响范围，监听不可用时保留定期校验。
- 排除索引数据库及其 WAL 等自身生成的事件，避免索引写入再次触发索引的循环。
- 优先处理应用变更，不让新增应用一直等待大目录扫描结束；保持嵌套授权目录的处理边界，保留扫描期间到达的新事件。
- 搜索窗口打开不再暂停索引。截图、OCR、文件操作和系统压力仍可让后台索引暂缓。
- 首次索引、全量重建、未完成目录恢复和手动刷新采用有上限的加速策略；CPU 节流按实际测量的索引工作计算，避免把其他界面或功能的耗时计入索引预算。
- 子目录无权限或扫描期间被移除时，继续处理其他可读内容；受限位置已有的索引按范围保留，不因局部访问失败清空整个目录的结果。
- 索引上限为 30 万项。达到上限后明确提示“结果不完整”，不会伪装成全部完成；应用可优先占用部分普通文件的索引缓存，但不会删除原始文件。

## 搜索界面与状态说明

- 结果分组按应用、PEEK 内置工具、文件和文件夹排列，应用优先。
- 内置工具仅显示有效的打开操作，不再展示移动、隔空投送等不适用操作及对应提示。
- 设置页区分“已有索引可用”“更新中”“受限位置”和“未完整收录”，避免把历史可用索引误当作本轮更新已经完成。
- 补充搜索范围、预览开关和索引进度的可访问性说明，并同步中英文本地化。

## 剪贴板隐私

- 在读取具体内容前检查剪贴板标记，忽略带有保密、临时、自动生成或 1Password 标记的内容；同一次剪贴板变化中任一项目带有这些标记时，跳过整次记录。
- 同步应用内中英文隐私政策与仓库隐私说明，明确保护依赖来源应用提供标记，不能识别所有未标记的敏感信息。
- 普通历史仍保存在本机沙盒内，未额外加密；升级不会自动清空旧历史，用户可在设置中主动清空或排除敏感应用。

## 验证与兼容范围

- 2026年10月13日提交前完整验证：421 项测试通过，Release Analyze、arm64 与 x86_64 Universal Release、本地化、隐私清单及资源检查通过。
- 新增回归覆盖索引统计与总量变化、增量事件、权限异常、容量限制、搜索进度显示、剪贴板敏感标记，以及截图路径隔离、像素尺寸和裁剪配置。
- 微信截图的人工确认来自当前测试设备，不等于所有微信与 macOS 版本均已验证。完整跨设备、旧系统及 VoiceOver 操作验收仍需补充。
- 应用继续支持 macOS 13 及以上；本次新的桌面截图路径仅用于 macOS 26 及以上。
